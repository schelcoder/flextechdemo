Design Notes & Constraints

⚠️ Databricks Apps cannot be public OCPP endpoint
OAuth/SSO mandatory, no anonymous access. CSMS must run co-located or behind separate ingress — not as a Databricks App directly.
✅ Co-located CSMS + chargers
Loopback WebSocket (ws://localhost) — no external ingress needed. Simulated chargers run as async Python coroutines in the same process/pod.
🔄 command_id UUIDv5 dedup
applied_commands PK ensures first path wins — exactly-once effect even if Lakebase NOTIFY and HTTP webhook both deliver. INSERT WHERE NOT EXISTS is idempotent.
⏱️ E2E latency P50 ~6–12s
Dominated by Zerobus ~5s time-to-table. Adequate for DFS dispatch windows (tens of minutes). Tail (P95 ~30–40s) fine for flex response. RTM mode reduces streaming lag to ms–300ms.
🔋 SetChargingProfile dead-man switch
validTo = event expiry timestamp. Charger self-heals to full power if CSMS connection drops or no update received — prevents permanent curtailment from a crash.
🔍 Verification gap: Accepted ≠ power reduced
OCPP Accepted only confirms message receipt. True verification requires streaming MeterValues join against commanded limit. Dashboard shows actual vs. target kW load curve.
